# Predicción de bajas de clientes (Churn)

## Objetivo
Construir un modelo que identifique a los clientes con riesgo de darse de baja,
para que la empresa pueda actuar antes de perderlos.

## Introducción y contexto
Una empresa de telecomunicaciones pierde todos los meses una parte de sus clientes.
Siguiendo la metodología CRISP-DM, se analizan los datos de los clientes, se entrena
un árbol de decisión y se publica una aplicación web (Streamlit) para usar el modelo.
